## Contracts

- Added or changed: added a copied 1024-byte send-path request authorized by
  an active opaque `trust_id`, native-selected 128-bit transfer IDs, a
  176-byte transfer event payload, and fixed four-record snapshot pages over a
  256-record bridge ceiling. Progress is monotonic and no greater than total
  bytes, completion requires equality, terminal state is immutable, and
  unknown or terminal command IDs return `STALE_HANDLE`. Events never expose
  local paths, remote relative paths, endpoints, protocol frames, keys, or
  certificates. Backend commands, state mutation, event publication, and
  shutdown have deterministic serialization; shutdown withdraws offers,
  projects active records as cancelled, rejects late updates, and waits for
  in-flight backend commands.

  lifecycle, discovery, pairing, trust, struct prefixes, callback ownership,
  and required v1 exports are unchanged. New inputs use

  callback re-entry rejection. No wire format, persisted schema, security
  profile, or protocol specification changed.
- ADR or protocol reference: extended ADR 0008 with the one-file transfer ABI,
