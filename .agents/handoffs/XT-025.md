## Contracts

- Added or changed: added the internal C++ session API for pairing attempts,
  admission, replay tombstones, established TLS capabilities, and cached
  authorization. Pairing attempts consume move-only admission leases and
  replay reservations; callers cannot manufacture pairing-window timestamps
  or act on reused connection IDs. Admission and replay capabilities serialize
  their process-wide shared state, while each attempt serializes external
  events through the durable trust-write boundary.
  Responders report `SELECT_ACK` write completion before SAS display.
  Exact-pin TLS remains provisional until local and peer
  `TRANSPORT_FINISHED` conditions succeed. TLS Finished values bind
  capabilities to one SSL handshake generation before the first exporter, and
  normal disconnect uses
  `SessionAuthority::Deactivate` without revoking durable trust. Pairing local
  errors retain the exact `0x1001` through `0x1012` registry. The existing
  `xnn_transfer_session` placeholder is replaced in place with one static
  target.

  changed. Generated tests consume XT-060's checked-in pairing vectors rather
  than defining another wire profile.

## Residual risk

- Known limitation: the accepted TLS provider still has no typed same-port
  server ALPN demultiplexer or inbound active-pin resolver. This task enforces
  exact pairing/established ALPN at capability construction and exact known
  peer pins for established channels, but it does not claim the missing
  production inbound socket composition. Network adapters must also assemble
  bounded complete frames, schedule the exposed monotonic deadlines, close
  invalidated sockets, report `SELECT_ACK` and local decision write completion,
  build the validated v1 transport context, exchange and verify both
  `TRANSPORT_FINISHED` values, call `Deactivate` before destroying a normal
  socket, and consult `SessionAuthority` before dispatch; those adapters do not
  exist in the current repository.
