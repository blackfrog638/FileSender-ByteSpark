  production socket adapter. XT-037 must serialize connection-wide outbound
  frame publication, drain frames in exact message-ID order, report actual
  ACK write completion, schedule monotonic `Advance` calls, and stop dispatch
  after a connection-fatal result. The shared sequence object validates IDs
  but intentionally does not claim transport publication ordering.

  but no peer-scope lookup capability, so this task does not substitute an

  registry before claiming resume or cross-connection fact replay.
