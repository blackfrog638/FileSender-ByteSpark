## Contracts

- Added or changed: extended ABI v1 additively with pairing-window, start,
  confirm, reject, revoke, pairing-snapshot, and trust-snapshot operations.
  Pairing attempts use native-random 128-bit handles, monotonic deadlines, five
  bounded SAS word indices, folded public errors, and stale-handle rejection.
  Trust records use process-local opaque IDs; unknown or already-revoked IDs
  revoke successfully to avoid a trust-record oracle. Presentation can submit
  only a peer selection or local confirm/reject decision and cannot supply
  identity, key, certificate, role, nonce, transcript, or protocol-frame data.
  Pairing/trust events share the existing 64-entry wakeup-and-drain queue and
  recover through revisioned fixed-size snapshots. Dart copies all payload
  bytes at the poll boundary and exposes immutable attempt-ID and SAS lists.
  Shutdown closes the native update sink before backend teardown so late
  pairing callbacks cannot publish events.
- Compatibility impact: `XNN_TRANSFER_ABI_VERSION` remains 1; existing ABI
  struct prefixes, lifecycle/discovery symbols, callback ownership, and
  caller-owned memory remain unchanged. New structs retain
  `struct_size`/`abi_version` negotiation and fixed layout assertions. No wire
  encoding, persisted schema, security profile, or protocol specification
  changed.
- ADR or protocol reference: ADR 0002, ADR 0003, and the extended ADR 0008
  pairing-operation decision.
