# Harness V2 Delivery Plans

Each `DP-*.json` is a normative, accepted Git document containing requirements,
observable criteria, negative definitions, implementation task mappings, and
required evidence.

A Plan belongs to exactly one Blueprint Change Set. Criterion statements and
negative definitions must exactly match the referenced Blueprint outcomes.
Plans contain no approval block, runtime state, CI identity, or acceptance
owner. Review of the protected commit is the approval fact.
